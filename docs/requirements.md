# 요구사항

프론트엔드와 백엔드가 공유하는 요구사항의 단일 출처다.
기능·화면에는 ID를 붙이고, 커밋·PR·각 영역 문서에서는 이 ID로 참조한다.

> **작성 방식**: 회의록(`docs/meetings/`)을 바탕으로 `/extract-requirements`를 실행해 갱신한다.
> 초안을 확인·승인한 뒤 반영하며, 각 항목의 `출처`에 근거 회의록을 적는다.
> 구현·설계 작업은 회의록이 아니라 이 문서를 기준으로 한다.

## 개요

방문 유아체육 전문 브랜드 **몽키즈**의 웹 서비스.

## 미결 사항

- SCR-002~011은 홈 시안에서 추정한 화면으로, 범위·구성은 확정이 필요하다.
- GNB "프로그램"과 카드 "정규 체육수업"이 같은 화면인지 (현재 SCR-003으로 묶어 둠)
- 견적 신청(SCR-011)이 기관 프로그램 문의(SCR-009)와 별도 화면인지, 같은 폼인지
- 고객센터(SCR-008)의 하위 구성 (공지, FAQ, 1:1 문의 등)
- 수업 현장(SCR-006)의 구성: 영상 포함 여부, 분류 기준(초안은 서비스 3종), 사진 상세 보기 방식, 기관명·아이 얼굴 노출 기준
- 강사 채용(SCR-007)이 안내만인지, 온라인 지원 폼까지 포함하는지
- 후기 전체 목록 화면이 필요한지
- 관리자 화면(문의·후기·수업 현장 콘텐츠 관리)이 필요한지. 홈 시안에는 나타나지 않는다.
