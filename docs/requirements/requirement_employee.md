# 요구사항 — 근태 관리 (직원용)

몽키즈 직원 근태 관리 GPS 웹 서비스의 요구사항 단일 출처다.
홈페이지 요구사항은 [requirement_homepage.md](requirement_homepage.md)에 있다.

> **작성 방식**: 회의록(`docs/meetings/`)을 바탕으로 `/extract-requirements`를 실행해 갱신한다.
> 초안을 확인·승인한 뒤 반영하며, 각 항목의 `출처`에 근거 회의록을 적는다.
> 구현·설계 작업은 회의록이 아니라 이 문서를 기준으로 한다.

## ID 규칙

홈페이지 ID와 겹치지 않도록 모든 ID 앞에 `EMP-`를 붙인다.

| 구분 | 형식 | 예 |
|---|---|---|
| 화면 (프론트엔드) | `EMP-SCR-{3자리 번호}` | `EMP-SCR-001` |
| 기능 (백엔드) | `EMP-FR-{3자리 번호}` | `EMP-FR-001` |
| 비기능 | `EMP-NFR-{3자리 번호}` | `EMP-NFR-001` |

- 번호는 이 문서 안에서 001부터 매긴다. 폐기한 ID는 다시 쓰지 않는다.
- 접두사 없는 `SCR-`·`FR-`·`NFR-`는 홈페이지([requirement_homepage.md](requirement_homepage.md)) ID다.

## 상태

기획 단계. 회의에서 나온 아이디어에 ID를 붙여 정리했으며, 아직 착수·확정되지 않았다(모든 항목 상태 `기획`).
착수가 결정되면 미결 사항을 정리하고 상태를 `확정`으로 바꾼다.

## 배경 (현재 문제)

- 직원이 거의 모바일로만 확인한다
- 직원과 의사소통이 어렵다
- 수업 컴플레인, 수업 스케줄 혼동이 생긴다

출처: 2026-10-29

| EMP-SCR-002 | 내 스케줄 | 직원이 할당받은 기관 수업과 휴강·보강 일정을 확인 | - | 기획 | 2026-10-29 |

## 기능 요구사항

기능은 백엔드 요구사항이다. 서버가 저장·검증·권한 처리·제공하는 내용을 적는다.

| ID | 기능 | 설명 | 관련 화면 | 상태 | 출처 |
|---|---|---|---|---|---|
| EMP-FR-001 | 위치 기반 출근 확인 | 직원의 위치와 할당된 기관 위치를 대조해 출근·퇴근 기록을 저장 | EMP-SCR-001 | 기획 | 2026-10-29 |
| EMP-FR-002 | 출퇴근 특이사항 | 출근·퇴근 기록에 특이사항을 함께 저장 | EMP-SCR-001 | 기획 | 2026-10-29 |
| EMP-FR-003 | 출근 기록 조회 | 직원은 자기 기록, 관리자는 직원별 출근 기록을 조회 | EMP-SCR-001, EMP-SCR-006 | 기획 | 2026-10-29 |
| EMP-FR-004 | 기관 수업 할당 | 관리자가 직원에게 기관 수업을 할당하고, 직원은 자기 할당을 조회 | EMP-SCR-002, EMP-SCR-006 | 기획 | 2026-10-29 |
| EMP-FR-005 | 휴강·보강 스케줄 | 수업의 휴강·보강 일정을 저장하고, 직원은 자기 스케줄을 조회 | EMP-SCR-002 | 기획 | 2026-10-29 |
| EMP-FR-006 | 수업 기록 저장 | 수업 사진 묶음과 특이사항 텍스트를 분리해 저장 (HTML 본문 방식 아님) | EMP-SCR-003 | 기획 | 2026-10-29 |
| EMP-FR-007 | 기록 열람 권한 | 수업·출퇴근 기록은 작성자 본인과 관리자만 조회. 관리자는 전 직원 기록 조회 | EMP-SCR-003, EMP-SCR-006 | 기획 | 2026-10-29 |
| EMP-FR-008 | 기관 특이사항 | 기관별 특이사항을 저장하고 직원·관리자가 함께 조회 | EMP-SCR-004 | 기획 | 2026-10-29 |
| EMP-FR-009 | 교구 현황 | 교구 종류·수량·상태·특이사항을 관리하고, 직원이 가져간 교구와 수업 후 특이사항을 기록 | EMP-SCR-005, EMP-SCR-006 | 기획 | 2026-10-29 |

## 미결 사항

- 구현 방식: 앱인지 웹(모바일 웹)인지 (출처: 2026-10-29)
- 출근 알림: 수신자(관리자 / 직원)와 수단(알림 / 메일) (출처: 2026-10-29)
- 위치 판정 기준: 기관 반경 몇 m를 출근으로 볼지, 위치 권한 거부 시 처리 (EMP-FR-001) (출처: 2026-10-29)
- 휴강·보강 등록 주체: 관리자만인지 직원도 가능한지 (EMP-FR-005) (출처: 2026-10-29)
- 기관 특이사항 수정 권한: 누구나인지 관리자만인지 (EMP-FR-008) (출처: 2026-10-29)
- 계정 체계: 홈페이지 직원 권한(FR-022)·로그인을 공유할지 별도로 둘지 (출처: 2026-10-29)
- 수업 사진 장수·용량 제한, 교구 상태 값 (EMP-FR-006, EMP-FR-009) (출처: 2026-10-29)
