# 논의 사항
- 모바일 ux/ui 변경 사항
    1. 모바일 버전 텍스트 줄바꿈. (ex 띄워쓰기 있으면 줄 바꿈 )
    2. 모바일 버전 후기 사진 확대 없이 한눈 바로 보이게. 
    3. 모바일 햄버거 간혈적으로 안보이는 증상 (아이폰 15 / 갤러시 s)
    4. 모바일 하단 버튼 1 대 1 상당 -> 1대1 방문 체육 상담 
    6. mongkiz.com/lab "궁금한 내용 검색 해보세요." 모바일 버전 잘림 수정
    7. 공감 버튼 하트 대신 바나나로 변경
    8. 선생님 소개 배율 죽이고 3 * 3으로
    9. 플로팅 메뉴 컴퓨터와 동일하게.  


- employee 기능 
    1. 수업 기록 상태 종료 완료-> 수업 종료로 변경,  수업 시작 뱃지 색깔 같은 것 수정. 
    2. 수업 종료 후 / 수업 특이 사항을 세세하게 작성하고 싶음. 
        - 대표가 궁금 것
            - 미리 선 질문을 작성: 조금 애매함
            - 예시로 작성한 화면으로 일단 구성. 

        - 어떻게 하면 직원들이 특이사항을 잘 남길 수 있을까?
            - 개인적으로 고민

    3. (관리자) 수업 기록 캘린더로 한눈에 볼 수 있도록 / 컴퓨터로 보고
        - 직원이 수업을 얼마큼 했는지를 확인하고 싶어서. / 
        - 행사나 특별활동에 수업을 할당하고 싶어서.

    4. 수업 시작 / 종료 시 홈페이지에 접속된 관리자가 알도록 한다. 
    5. 끝났을 때도 기관 위치를 인식하여 수업 종료 기능을 활성화 하도록 한다. 
    6. 수업을 단일이 아닌 하루 단위 묶음으로 변경. 

- 세부 수업 보러가기 -> 계획안을 보여줌 연간 / 월간 (새로운 페이지 필요)
    - 세부 수업 인증된 사람만 보여주고 싶고 
    - 인증된 사람에게는 전부 다 보여준다. 
    - 처음에는 1개월만 보여주고 / 인증된 회원의 한에서는 전체를 보여준다
    - 고유번호증 / 사업자 받을 수 있는데 비용 분석

- 시간표 기록
    최적의 시간표 할당하기
    - 한 기관에는 대부분 한 직원이 맡아서 한다 (가혹 두명이지만 이는 생각하지 않는다)
    - 직원 하루에 최대 8 개 일주일 총 40개정도
    - 점심 시간 없음
    - 이동은 차로 하고
    - 수업 시작 전 5분전 도착을 목표로한다.
