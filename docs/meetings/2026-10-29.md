# 추가 한 기능

1. 플로팅 메뉴 임시 수정
    - 카카오톡 상담 -> 후기 보러가기
    - 추가 수정 사항 논의 필요
    - 결정 사항: 전화 문의는 남겨두고, 후기 보러가기  변경 안 유지.

2. 상담 접수 완료 시 관리자 계정에게 알림이 오도록 설정
    - 상담 신청에 대해 인증/검증이 이뤄지지 않고 있음으로 웹 서비스 내 알람 기능만 활성
    - 추후, 상담 신청에 대한 검증이 이뤄지면 이메일 발신 혹은 알림톡으로 전송하도록 전환
    - 결정 사항: 승인

3. 관리자 화면 추가
    - 회원 권한 탭 
        - 회원의 권한을 직원으로 변경 가능
    - 상담 신청 탭
        - 상담 신청 이력 및 상태 변경 가능
        - "신규" 상태인 경우 관리자 버튼에 지속적으로 알람이 표시
    - 후기 관리 탭 추가
        - 부적절한 후기를 숨길 수 있음
        - 추후 승인된 후기만 화면에 보이도록 
    - 결정 사항: 승인

4. 모바일 화면 문제 해결
    - 햄버거 버튼이 안보이는 이슈 해결
    - 로그인 버튼 헤더로 이동
    - 결정 사항: 승인

5. 후기 화면 개편
    - 목적: 후기 화면의 글 과 내용이 잘 전달되지 못함
    - 원인
        1. 리뷰 아이템(리뷰 내용)이 top 마진이 없어서 바텀 여백이 과하게 존재. 
        2. 리뷰 사진을 크게 볼수 없음
        3. 리뷰 답글이 리뷰 아이템 카드에 종속되어 리뷰 포토와 배치가 부자연러움
        4. 리뷰 아이템 내용이 길어지는 경우 화면을 너무 차지한다.
    - 변경 계획
        1. 리뷰 아이템과 리뷰 포토를 같은 카드에 넣는다. 
        2. 답글은 1번의 공통된 컴포넌트 밑에 넣는다. 
        3. 리뷰 아이템 내용이 리뷰 사진의 크기를 넘어가는 시점에서는 더보기로 표시 후 접어둔다.
        4. 전체 리뷰 화면에서 보여지는 사진의 크기를 줄이고, 클릭 시 크게 확인 가능하도록 수정.
    - 결정 사항: 승인

6. 마이 페이지
    - 목적: 회원의 개인 정보 (이메일, 이름, 전화번호) 를 확인하고 회원 탈퇴
    - 결정 사항: 승인

- 홈페이지 MVP  확정

7. 후기 권한
    - 로그인 한 사용자만 후기 작성이 가능하다
    - 후기 작성은 별도의 링크를 전달하여 작성이 가능하도록 하여, 비식별자의 후기 작성 가능성을 줄인다. 
    - 결정
