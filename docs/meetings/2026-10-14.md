## 1. 홈페이지 안건 (추가한 기능)

### 1-1. 플로팅 메뉴 임시 수정

- 내용: 카카오톡 상담 → 후기 보러가기
- **결정**: 전화 문의는 남겨 두고, '후기 보러가기' 변경안 유지
- 후속 과제: 추가 수정 사항 논의 필요

### 1-2. 상담 접수 완료 시 관리자 알림

- 배경: 상담 신청에 대한 인증·검증이 이뤄지지 않고 있음
- 내용: 상담 접수가 완료되면 관리자 계정에 알림이 오도록 설정. 웹 서비스 내 알림 기능만 활성화
- **결정**: 승인
- 후속 과제: 상담 신청 검증이 도입되면 이메일 발신 또는 알림톡 전송으로 전환

### 1-3. 관리자 화면 추가

| 탭 | 기능 |
|---|---|
| 회원 권한 | 회원의 권한을 직원으로 변경 |
| 상담 신청 | 상담 신청 이력 확인 및 상태 변경. "신규" 상태가 있으면 관리자 버튼에 알림이 계속 표시됨 |
| 후기 관리 | 부적절한 후기 숨김 |

- **결정**: 승인
- 후속 과제: 승인된 후기만 화면에 보이도록 변경

### 1-4. 모바일 화면 문제 해결

- 햄버거 버튼이 보이지 않는 이슈 해결
- 로그인 버튼을 헤더로 이동
- **결정**: 승인

### 1-5. 후기 화면 개편

- 목적: 후기 화면의 글과 내용이 잘 전달되지 못함

**원인**
1. 리뷰 아이템(리뷰 내용)에 top 마진이 없어 바텀 여백이 과하게 존재
2. 리뷰 사진을 크게 볼 수 없음
3. 리뷰 답글이 리뷰 아이템 카드에 종속되어 리뷰 포토와 배치가 부자연스러움
4. 리뷰 내용이 길어지면 화면을 너무 많이 차지함

**변경 계획**
1. 리뷰 아이템과 리뷰 포토를 같은 카드에 넣는다
2. 답글은 1번의 공통 컴포넌트 밑에 넣는다
3. 리뷰 내용이 리뷰 사진 크기를 넘어가는 시점부터 '더보기'로 접어 둔다
4. 전체 리뷰 화면의 사진 크기를 줄이고, 클릭 시 크게 볼 수 있게 한다

- **결정**: 승인

### 1-6. 마이페이지

- 목적: 회원이 개인 정보(이메일, 이름, 전화번호)를 확인하고 회원 탈퇴할 수 있게 함
- **결정**: 승인

### 1-7. 후기 작성 권한

- 후기 작성은 별도 링크를 전달해 작성하도록 하여, 비식별자의 후기 작성 가능성을 줄인다

### 프로젝트 2. 근태 관리 GPS 웹 서비스

**현재 문제**
- 99% 모바일로 확인
- 직원과 의사소통 곤란
- 수업 컴플레인, 수업 스케줄 혼동

**기획 아이디어**
- 위치 기반 출근 확인 (기관별)
  - 직원이 출근할 때 알림 또는 메일이 왔으면 좋겠음
  - 관리자가 각 직원의 출근 기록 확인
  - 관리자는 직원에게 기관 수업을 할당하고, 직원은 기관을 할당받음
- 출퇴근 시 특이사항 기록
- 수업 사진 업로드
  - HTML 태그 방식이 아니라 사진 묶음 따로, 특이사항 따로
- 휴강·보강 스케줄
  - 직원이 자신의 스케줄을 확인
- 기관별 특이사항을 적어 서로 공유
  - 예: 유치원 주차장 협소, 관리사무소 2층에 있음 등
- 기록 열람 권한
  - 작성자는 자신이 작성한 기록만 확인
  - 관리자는 전 직원 기록 확인
- 교구 현황
  - 직원이 가져간 교구를 기록하고 수업 후 특이사항 작성
  - 교구 종류, 수량, 상태, 특이사항
