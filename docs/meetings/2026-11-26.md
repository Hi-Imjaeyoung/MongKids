# 기능 논의
## 미배정 수업 담당 직원 추천 (근태 관리)

- 목적: 미배정 수업 1건에 대해, 직원 데이터를 바탕으로 담당 직원 후보를 순위대로 추천한다.
  최종 배정은 관리자가 한다.
- 소속: 근태 관리 (requirement_employee)

### 배정 가능 조건
- 해당 수업 시간과 겹치는 수업이 없어야 한다.
- 그날 바로 앞 수업이 있으면: 앞 수업 종료 + 이동 시간 ≤ 해당 수업 시작 3분 전
- 그날 바로 뒤 수업이 있으면: 해당 수업 종료 + 이동 시간 ≤ 뒤 수업 시작 3분 전
- 직원의 출발지·귀가지는 고려하지 않는다. (그날 첫 수업·마지막 수업이면 해당 방향 이동은 계산하지 않음)
- 담당 조건(자격 등)은 현재 없다.

### 추천 순위
1. 배정 가능한 직원만 후보로 한다.
2. 그 주 총 수업 수가 적은 순
3. 동점이면 추가 이동 시간이 짧은 순
   - 추가 이동 = (앞 → 해당) + (해당 → 뒤) − (앞 → 뒤), 없는 구간은 0

### 화면 표시
- 후보 직원을 순위대로 표시한다. (그 주 수업 수, 추가 이동 시간, 앞·뒤 수업)
- 배정 불가 직원도 사유와 함께 표시한다. (예: 시간 겹침, 이동 시간 부족 — 필요 25분 / 여유 15분)

### 이동 시간 데이터
- 지도 API(차량 경로)로 기관 간 이동 시간을 조회하고, 조회한 값은 저장해 재사용한다.
- 사용할 지도 API는 카카오모빌리
